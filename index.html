Spring Boot를 배우던 시절을 기억합니다. 복잡한 의존성 관리, 무거운 실행 환경, 어렵게 느껴지던 보안 설정. 비즈니스를 만들기 전에 프레임워크의 복잡함과 먼저 씨름해야 했습니다.

오랜 시간 익힌 개발 방식까지 버려야 할까요?
익숙한 뼈대는 가져오고, 그 안의 추상화와 실행 구조는 더 단순하게. Spine은 이 고민에서 출발했습니다.

이미 배운 것컨트롤러, 서비스, 의존성 주입

  • 익숙한 사용성
  • 명시적인 책임
  • 읽을 수 있는 실행

  • 가벼운 시작
새롭게 할 수 있는 것더 작은 자원으로, 더 넓은 가능성

배움은 이어지고, 가능성은 넓어지도록.

익숙한 뼈대,
가벼운 실행🦴

컨트롤러, 서비스와 생성자 주입.
익숙한 개발 구조를 Go 위에서 이어갑니다.

Spine은 실행 순서와 책임을 코드 구조에 드러내는 백엔드 프레임워크입니다. 요청이 어떻게 해석되고 실행되는지 코드에서 읽을 수 있도록.

업무의 의도가 남는 곳

컨트롤러는 요청을 받고, 서비스에 업무를 맡깁니다. 메서드의 입력과 반환 타입에서 API의 형태를 읽습니다. 

func (c *UserController) GetUser(
    id input.Path[int],
) (httpx.Response[*User], error) {
    user, err := c.service.Find(*id)
    return httpx.Response[*User]{Body: user}, err
}

내가 배운 방식이 아니라서,
더 나은 기술을 포기하는 일이 없도록.

안전하고 빠른 기술을 누구나 누릴 수 있어야 합니다. 가벼운 실행은 작은 자원을 더 알차게 쓰려는 사람에게도 필요합니다. 고성능이 특별한 환경만의 선택지로 남지 않기를 바랍니다.

# 계정을 연결하고
spine cloud auth login

# 프로젝트에서 배포합니다
spine deploy
  1. 계정 연결브라우저에서 코드 승인
  2. 배포 접수터미널에서 진행 확인
  3. 앱 실행서버의 실행 환경으로
  4. 세상과 연결웹에서 앱과 공개 주소 확인

실제 배포 없이 과정을 살펴봅니다.

누구나 도전할 수
있는 세상으로

Spine CLI로 첫 구조를 만들고, AI와 함께 코드를 발전시키고, Spine Cloud로 결과물을 공개하는 경험. 기술을 배우는 시간과 처음 시작하는 비용이 새로운 발명을 가로막지 않기를 바랍니다.
